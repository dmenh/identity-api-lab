# Support the project

Identity API Lab is designed and maintained by Dinesh. It is free to explore and run locally under the included repository license.

If the project helped you learn identity and access management, API integration, authentication or connector development, you can optionally support its continued development.

## Support options

- **Razorpay:** [Support Identity API Lab](https://razorpay.me/@dineshm01)
- **GitHub:** Use the **Sponsor** button at the top of the repository after GitHub Sponsors enrollment is active.
- **Partnerships:** Contact [Dinesh on LinkedIn](https://www.linkedin.com/in/dineshwarmanukonda/).

Contributions help fund protocol compatibility work, security testing, documentation, sample integrations and hosted demonstration environments.

Sponsorship does not purchase access to real banking systems or customer data. The project is a synthetic identity integration lab, and the repository license continues to apply.
